# 고전 표지 제작 기록

각 작품의 기존 카탈로그 요약과 연결된 전사 원문을 장면 선정의 출발점으로 사용했다. 표지는 내장 이미지 생성 도구로 만든 해석적 삽화이며, 사용 모델명은 도구에서 확인되지 않았다. 작품명과 저자는 이미지에 새기지 않고 화면 텍스트로 표시한다.

추가 참고: [한국민족문화대백과 동백꽃](https://encykorea.aks.ac.kr/Article/E0016498), [메밀꽃 필 무렵](https://encykorea.aks.ac.kr/Article/E0018494), [김유정 작품집](https://encykorea.aks.ac.kr/Article/E0016499). 각 작품의 공유마당 기록 및 전사 원문 링크는 아래에 기록했다. 전사본 이용 조건을 이 작업에서 새로 검증한 것은 아니다.

공통 프롬프트: 20세기 초 한국 배경의 세로 3:4 문학 표지, 시네마틱 회화적 사실주의, 절제된 자연색과 분위기 있는 빛. 글자·로고·워터마크 없이 제작.
