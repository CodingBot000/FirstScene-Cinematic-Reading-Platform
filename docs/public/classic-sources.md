# FirstScene 고전 20편 원문·출처 원장

기준일: 2026-11-23. 기존 오리지널 2편은 `/read/[storyId]`에서 그대로 제공하고, 고전 20편은 `/classics/[id]`에서 일반 읽기로 제공합니다. 공개 예정 콘셉트 34편은 여전히 본문이 없습니다.

## 이용 조건과 범위

- 한국저작권위원회 **공유마당**의 각 작품 기록을 기준으로 원작의 저작권 보호기간 만료를 확인했습니다. 20편 모두 한국 근대문학의 보호기간 만료 원작입니다.
- 본문 텍스트는 아래 GitHub 공개 코퍼스의 특정 커밋을 확인한 뒤 반입했습니다. **공유마당 TXT 파일을 직접 다운로드한 것은 아니며**, 공개 전사본은 원전의 띄어쓰기·표기·OCR 교정 등에서 차이가 날 수 있습니다.
- **원작의 보호기간 만료와 전사·현대 편집본의 별도 저작권은 구분됩니다.** 이번 작업에는 출판사의 현대 번역, 해설, 표지 이미지, 삽화를 복제하지 않았습니다. 별도 편집물의 저작권 여부는 전사 원본별로 재확인이 필요합니다.
- 원작자와 전사 출처는 개별 리더 하단에 표시합니다. FirstScene이 고전의 원저자·창작자라는 주장은 하지 않습니다. 전사본의 재게시 권리에 관한 이의가 생기면 원문 검토 및 교체가 가능하도록 독립 콘텐츠 모듈로 구성했습니다.
- 작품 본문은 JSON 파일에 텍스트로 보존하고 React 텍스트 노드로 서버 렌더링합니다. 기존 오리지널 2편의 6씬·36비트 계약과 독서 상태 동기화에는 손대지 않았습니다.

## 최초 제안 대비 변경

최초 후보 중 **노다지**, **황소와 도깨비**, **탁류**는 이번 반입에서 신뢰할 만한 전문 전사본을 확보하지 못해 제외했습니다. 대신 **레디메이드 인생**, **술 권하는 사회**, **고향**을 추가해 고전 전체를 20편으로 유지했습니다. 따라서 이 목록은 최초 제안과 정확히 일치하지 않습니다.

## 구현 경계

- `content/classics/catalog.json`: 표시용 제목·저자·소개·공유마당 원작·전사본 고정 링크
- `content/classics/works/*.json`: 원문 20편 각각 독립 JSON
- `apps/web/lib/classic-content.ts`: 작품 id별 서버 동적 import (초기 클라이언트 목록과 본문 분리)
- `apps/web/app/classics/[id]/page.tsx`: 정적 경로 생성·본문 SSR·출처 링크·404 처리
- `apps/web/lib/discovery-model.ts`: 오리지널 2편/고전 20편/미발행 콘셉트 34편 상태 구분
- 고전에는 오리지널 작품의 6씬 이미지·시네마틱 전환·개인 진도·북마크를 붙인 것으로 주장하지 않습니다.
