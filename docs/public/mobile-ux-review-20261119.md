# FirstScene 모바일 사용자 흐름 QA · 2026-11-19

## 대상과 목표

랜딩 → 탐색 → 작품 소개 → 읽기 → 내 서재 → 읽기 설정의 주요 모바일 흐름을 검토합니다. 완결된 두 편과 공개 예정인 34편의 상태를 혼동하지 않도록 기존 발행 구조를 유지하고, UI 개선은 공개 컴포넌트/CSS 수준으로 제한했습니다.

- **기기 범위:** 자동 Chromium·WebKit의 320/390/430px 뷰포트. 별도로 이전 PR의 360/768/900/1023px 프롤로그 검사를 유지합니다.
- **데이터 범위:** QA 전용 임시 PostgreSQL에서 저장·서재 흐름 확인. 운영 Neon, 버킷, 원고, 로그인, 권한에 변경 없음.
- **검증 제한:** 브라우저 에뮬레이션은 실제 iPhone/Android의 주소창·키보드·터치 감각을 대신하지 않습니다.

## 책임 분리 평가

`CinematicPrologue`의 장면·GSAP·스타일 분리, `Discovery`의 메타데이터 기반 예정작 탐색, `StoryActions`/독서 상태 저장 레이어를 유지했습니다. 이번 범위에서 새 전역 상태, DB 테이블, API, 외부 패키지를 추가하지 않았습니다. `Library`의 빈 상태 조건만 변경했고, 포커스 복구는 해당 컴포넌트가 책임지도록 했습니다.

**남은 기술 부채:** `apps/web/app/site.css`는 공개 UI의 다양한 스타일이 길게 집약되어 있습니다. 차후 의미 있는 분리가 필요하지만, 현재 PR에서는 관련 선택자만 변경해 회귀 위험을 줄였습니다. 탐색·랜딩의 미리보기 카드 표현도 중복돼 있어 별도 UI 공통화 후보입니다. 이 개선과 함께 불필요한 추상화를 미리 도입하지 않았습니다.
