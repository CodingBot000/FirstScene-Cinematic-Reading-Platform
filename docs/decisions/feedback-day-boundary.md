# 피드백 일별 제한 결정

사용자가 “한국 시간 자정 (권장)”을 선택했습니다. 피드백 제한은 세션·작품별 한국 시간(Asia/Seoul) 달력 하루에5회이며 매일00:00에 초기화합니다. UTC자정이나 rolling24시간을 사용하지 않습니다.

판정은 클라이언트 시간과DB세션timezone에 의존하지 않고 서버DB시각을 Asia/Seoul로 변환해 수행합니다. 동시 요청은 세션 잠금으로 직렬화합니다. 동일 operationId의 동일 payload 재시도는 원래 결과를 재생하며 일일 횟수를 추가 소비하지 않습니다. 한도 거절에는 다음 한국 자정까지의 Retry-After를 제공합니다. 사용자 입력 timestamp로 경계를 우회할 수 없습니다.

이 결정은 기존5회 한도의 일별 경계만 확정합니다. 브라우저별 익명 세션, 전체 쓰기120회/분, 세션30일 및 삭제 정책은 유지합니다.
